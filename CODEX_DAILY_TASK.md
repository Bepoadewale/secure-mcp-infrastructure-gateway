# Daily Engineering Task

Read control files, fetch/inspect branch/PR, run `PYTHONPATH=gateway/src python3 -m pytest -q`, then ask: “What is the highest-value remaining blocker preventing PORTFOLIO COMPLETE — LOCAL-FIRST SCOPE?” Advance that real-MCP P0 slice. Do not select polish/P2 work while blockers remain. Validate against actual fixture traffic before changing status. Update status/backlog, commit/push branch only, report exact tools/policy/approval evidence and remaining gaps.

As the project approaches completion, clean-room reproducibility becomes P0. Before declaring completion: tear down Project-owned infrastructure; verify teardown; bootstrap clean; smoke; run primary and failure/security demos; validate; clean again; bootstrap a second time; and record evidence. If either rebuild fails, fix it before cosmetic work.
